Fonctionnalités

01

Saisons MotoGP

Consultation des différentes saisons du championnat MotoGP. Navigation entre les années, résultats globaux et classements par saison.

02

Circuits

Liste et détail des circuits du calendrier MotoGP — nom, pays, longueur, nombre de virages. Données stockées en base et exposées via l'API.

03

Pilotes

Fiches pilotes avec informations clés — nationalité, numéro, équipe, palmarès. Consultables depuis le frontend React via les endpoints de l'API.

04

Statistiques

Affichage de statistiques de courses — victoires, podiums, points. Données agrégées côté backend et affichées dynamiquement dans l'interface React.

05

API REST maison

Tous les endpoints construits from scratch avec FastAPI — pas d'API externe. La base de données est peuplée manuellement par l'équipe avec les données MotoGP.

06

Interface React

Frontend composants React — navigation entre les pages, affichage des données en cartes, appels API via fetch, état géré avec les hooks React.

Ce que j'ai appris

01

Python & FastAPI

Construire une API REST complète en Python avec FastAPI — routes, modèles Pydantic, connexion base de données, documentation Swagger auto-générée. Premier projet backend Python sérieux.

02

React — frontend moderne

Composants fonctionnels React, hooks (useState, useEffect), appels API avec fetch, gestion de l'état. Première application React connectée à une vraie API maison.

03

Architecture fullstack

Faire communiquer un backend Python et un frontend React — CORS, format JSON, séparation des responsabilités, organisation du projet en deux parties indépendantes.

04

Travail en équipe de 4

Répartir les tâches entre backend et frontend, travailler sur des branches Git séparées, synchroniser les endpoints API avec les besoins du frontend, revue de code croisée.
