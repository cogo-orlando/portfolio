Partage réseau
+ Annuaire

Un espace de fichiers partagé pour plusieurs équipes : chacun se connecte avec son compte de l'annuaire, n'accède qu'à ses dossiers, et chaque action est tracée.

02 //

Ce qui a été mis en place

Serveur de fichiers Samba

Un partage par équipe et un partage commun, accessibles via SMB depuis les postes Linux et Windows.

Authentification centralisée

Les comptes et les groupes viennent de l'annuaire : un seul identifiant par personne.

Droits par équipe

Chaque groupe n'accède qu'à ses propres dossiers, grâce aux ACL.

Traçabilité

Le module full_audit enregistre qui a ouvert, modifié ou supprimé quoi, et depuis quelle machine.

03 //

Un partage tracé, en pratique

Extrait de /etc/samba/smb.conffull_audit
[equipe-a]
   path = /srv/samba/equipe-a
   valid users = @equipe-a
   read only = no
   vfs objects = full_audit
   full_audit:prefix = %u|%I|%m|%S
   full_audit:success = open read write rename unlink
   full_audit:failure = connect
04 //

Ce que j'ai appris

  • Penser en groupes, pas en utilisateurs : les droits donnés aux groupes de l'annuaire restent gérables quand l'équipe grandit.
  • Tracer, c'est sécuriser : sans journal des accès, impossible de savoir qui a supprimé un fichier.
  • Travailler à deux sur les mêmes VMs : Proxmox permet de partager un vrai environnement de test.
