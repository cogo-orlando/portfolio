What I learned

  • Testing an API, not just writing it: checking every route, its responses and its error cases, so the frontend can rely on it.
  • Making two applications talk: a Python backend and a React frontend, linked by a clear contract (routes, JSON, CORS).
  • Keeping a team of four in sync: one branch per task, and API routes agreed on together before coding.
