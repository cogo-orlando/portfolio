An L2 switch works at the data link layer — it switches MAC frames between ports and handles VLANs, but doesn't route. An L3 switch does all that plus IP routing — it can route between VLANs without an external router, and you can configure DHCP directly on it. In my Cisco project, I used 3650-24PS (L3) switches for inter-VLAN routing and DHCP, and 2960-24TT (L2) switches for distribution within each site.

gosec is a static security scanner for Go — it analyzes source code and flags potential vulnerabilities: unchecked errors (G104), SQL queries built from strings (G201/G202), data flowing from user input into risky calls like an SSRF (G704). On my portfolio, gosec runs on every push through GitHub Actions. Result: {{template "nb-gosec"}} issues across the repo. It isn't optional — it's part of my definition of “done”.
