Ce que j'ai appris

  • Tester une API, pas seulement l'écrire : vérifier chaque route, ses réponses et ses cas d'erreur, pour que le frontend puisse compter dessus.
  • Faire dialoguer deux applications : un backend Python et un frontend React, reliés par un contrat clair (routes, JSON, CORS).
  • Synchroniser une équipe de quatre : une branche par tâche, et les routes de l'API décidées ensemble avant de coder.
