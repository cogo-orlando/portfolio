Technical choices

Hub-and-spoke

Each site reaches a central router over a dedicated WAN link, with static routes.

Inter-VLAN routing on L3 switches

The 3650 switches route between the site's VLANs without going through a router.

DHCP close to the users

One DHCP pool per VLAN, configured directly on the L3 switches.

Central services

The DNS and web servers in Stockholm are reachable from every site.

What I learned

  • Plan before wiring: a consistent addressing plan prevents most routing failures.
  • An L3 switch changes the design: inter-VLAN routing and DHCP close to the users.
  • Test methodically: ping and traceroute site by site to isolate each issue.
