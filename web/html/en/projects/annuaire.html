Network share
+ Directory

A shared file space for several teams: everyone signs in with their directory account, only sees their own folders, and every action is logged.

01 //

At a glance

The needShared and per-team folders, controlled access
StackLinux · Samba · LDAP · Proxmox VE
SecurityPer-team ACLs · full_audit log
EnvironmentServer and client VMs on Proxmox
02 //

What we built

Samba file server

One share per team plus a common share, reachable over SMB from Linux and Windows machines.

Central authentication

Accounts and groups come from the directory: one login per person.

Per-team permissions

Each group only reaches its own folders, using ACLs.

Audit trail

The full_audit module logs who opened, changed or deleted what, and from which machine.

03 //

A logged share, in practice

Excerpt from /etc/samba/smb.conffull_audit
[equipe-a]
   path = /srv/samba/equipe-a
   valid users = @equipe-a
   read only = no
   vfs objects = full_audit
   full_audit:prefix = %u|%I|%m|%S
   full_audit:success = open read write rename unlink
   full_audit:failure = connect
04 //

What I learned

  • Think in groups, not users: permissions given to directory groups stay manageable as the team grows.
  • Logging is security: without an access log, there is no way to know who deleted a file.
  • Two people on the same VMs: Proxmox makes it possible to share a real test environment.
