02 //

What the forum does

Secure accounts

Passwords hashed with bcrypt, expiring sessions in HttpOnly cookies, one active session per user.

Posts, categories and images

Posts sorted by category, JPEG / PNG / GIF images up to 20 MB, with clear errors when a file is rejected.

Role-based moderation

Four roles (guest, user, moderator, admin) checked by a middleware on every action.

Google and GitHub sign-in

Full OAuth 2.0 flow, linked to local accounts.

Likes, filters and notifications

Reactions on posts and comments, category filters, notifications and an activity page.

Protection and deployment

HTTPS, rate limiting against brute force, fully containerized with Docker.

What I learned

  • Design the database before coding: the relational schema (keys, joins) guided the rest of the project.
  • Security starts on day one: bcrypt, expiring sessions, role-protected routes, limited attempts.
  • Four people on one codebase: one branch per feature, reviewed pull requests, and shared conventions.
